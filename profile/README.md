## Promptkura

The AI prompt and skill library. 13,000+ prompts, Claude skills, agents and rules, plus in-house Originals, installed into your project in one command.

```bash
npx promptkura add obra/test-driven-development
```

Works with Claude Code, Cursor, Codex, GitHub Copilot, ChatGPT and Gemini.
